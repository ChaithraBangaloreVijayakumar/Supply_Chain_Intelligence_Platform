Supply Chain Intelligence Platform

Technology Stack:
Microsoft Fabric (Lakehouse, Warehouse, PySpark) · Delta Lake · LightGBM · MLflow · Power BI · DAX

Architecture: End-to-end medallion ETL pipeline (bronze/silver/gold) in Microsoft Fabric processing 180K+ order items into a 7-dimensional star schema. Late-delivery risk prediction model trained on order-time features only (no leakage) with out-of-time holdout validation (AUC 0.77, Precision 83%, Recall 60%). Multi-page Power BI dashboard with 30+ DAX measures, risk scoring, model calibration, KPI analysis, anomaly detection, decomposition trees, key influencer analysis, and drill-through order detail.

Note: This portfolio displays static dashboard previews. Live interactive dashboard available to organization members in Power BI Service.
